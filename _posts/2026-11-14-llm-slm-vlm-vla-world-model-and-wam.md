More acronyms. But what do they actually mean?

In my previous post, I compared generative AI, agentic AI, physical AI and AGI. This time, I’m looking at the models behind some of those capabilities.

Let’s use one everyday object: a red mug. ☕

## 💬 LLM — Large Language Model

“Explain how to move the mug.”

It generates a written answer or code. Producing instructions is one thing; physically carrying them out requires more.

## 📱 SLM — Small Language Model

“Summarize those steps on my device.”

It handles language tasks with a smaller model and typically fewer computing resources. The distinction here is size, rather than a completely different capability.

## 👀 VLM — Vision-Language Model

“Where is the red mug?”

It combines visual information with language to answer questions about what it sees.

## 🤖 VLA — Vision-Language-Action Model

“Pick up the red mug.”

It connects visual observations and instructions with robot actions.

## 🌍 World Model

“What might happen if the mug is pushed?”

Some world models predict how a scene changes. Others, such as World Labs’ Marble, focus on generating 3D environments.

## 🎬 WAM — World Action Model

“Predict the lift and generate the movement.”

It connects predictions of future world states with the actions needed to produce them.

These categories overlap. A language model can also support vision, and a robot can combine several approaches.

Coming from embedded software and sensors, I find the connection between perception, prediction and action particularly interesting. The challenge extends beyond generating a convincing answer to making a system work in a changing physical environment.
