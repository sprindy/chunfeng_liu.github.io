In my last post, I explored the processors behind AI. This time, let’s look at how AI learns—and how it might help improve itself.

These terms often appear together, but they describe different things.

![Illustrated guide to machine learning, deep learning, reinforcement learning, and recursive self-improvement.]({{ '/assets/blog/ai-jargon-101/ml-dl-rl-and-rsi.jpg' | relative_url }})

## 📚 ML — Machine Learning

The broad idea of learning patterns or behavior from data and experience.

Think of a system learning to recognize spam from past emails.

## 🕸️ DL — Deep Learning

A branch of ML that uses neural networks with many layers to learn complex patterns.

It powers capabilities such as image recognition, speech processing, and large language models.

## 🎯 RL — Reinforcement Learning

An approach within ML where a system learns which actions lead to higher rewards.

Imagine a robot practicing movements and receiving rewards for staying balanced and reaching its destination.

DL and RL can work together: **Deep RL uses deep neural networks to learn a strategy through rewards.**

## 🔄 RSI — Recursive Self-Improvement

A process where an AI system improves itself, then uses the improved version to make further improvements.

Imagine a coding agent improving its own tools, testing those changes, and using the better tools to improve itself again.

The “recursive” part matters: one improvement helps produce the next.

**A trend I’m watching is the move toward RSI.**

AI is increasingly being explored as a participant in its own development—helping improve code, tools, experiments, and learning methods.

Sakana AI’s Darwin Gödel Machine is one research example: it modifies its coding-agent software and evaluates the changes on programming benchmarks.

That is a bounded demonstration of self-improvement. It doesn’t mean the system can improve without limits, or that every change makes it better.

My view is that the ability to **propose, test, and build on improvements** will become increasingly important. Reliable evaluation will matter just as much as generating new ideas.

One distinction to keep in mind: **ML is the umbrella. DL and RL can combine. RSI is a self-improvement process that may use them.**

So this isn’t a simple timeline where RSI replaces ML, DL, or RL. It adds another feedback loop to how AI systems are developed.

Would you trust AI to improve its own software if every change had to pass independent tests?

Research example: <https://sakana.ai/dgm/>
