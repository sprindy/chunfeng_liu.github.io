ChatGPT subscription and API are not the same thing — even if they can use the same underlying AI model.

So I’m starting a small series called AI Jargon 101, where I explain common AI concepts with simple analogies and visuals.

For the first one: Subscription vs API

Think of AI tokens like water.

![AI subscriptions and APIs compared using tap water and pipelines]({{ '/assets/blog/ai-jargon-101/subscription-vs-api.jpg' | relative_url }})

## 💧 Subscription = tap water

You pay monthly or annually for access to a certain capacity.

Open the app, start chatting, and use it within your plan.

## 🔧 API = pipeline

You build a connection to the AI service, get a digital key, and pay based on usage.

It gives you much more control and is especially useful for programming, automation, agents, and products.

Both give you access to the same basic resource — AI model capability / tokens — but the way you access and use it is different.

Subscription is usually more conversation-oriented.

API is more about integration, automation, control, and scale.
